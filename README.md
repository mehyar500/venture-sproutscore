# SproutScore

**Is your daycare actually safe?** — NYC daycare inspection decoder.

Free-first PWA: search any NYC daycare free, see inspections/flagged counts,
standing vs the NYC average, and raw flagged codes. The $19 one-time report
decodes every violation into plain English (what happened, severity, fixed or
not) with a transparent safety score, comparisons, tour questions, and a
printable tour card. The $29 3-pack decodes three centers.

## Money flow

- Checkout: `POST https://mehyar.us/api/pay/checkout` with
  `product_id` ∈ {`sproutscore-report`, `sproutscore-3pack`}, `test: true`.
  Price comes from D1 `billing_products` — never from the client.
- Status: `GET https://mehyar.us/api/pay/status?token=` (polled by success.html).
- Fulfillment (mehyar-web sibling worker): writes `sproutscore_orders`
  (`access_token` = billing token), emails the report link from `team@mehyar.us`.

## Data integration

`~/workspace/sproutscore/data/` is the sibling data worker's output dir —
**currently empty**. When `centers.json` + `violation-translations.json` land,
run `scripts/sync-data.sh` to regenerate the teaser bundle and the server
dataset. The public/private split is preserved: decodes never enter the public
JSON. See `DATA_SWAP.md` and `INTEGRATION.md`.

## Email

- Subscribe writes `sproutscore_subscribers` AND `subscribers_global`
  (brand=`sproutscore`); partial failures are reported, not hidden.
- Unsubscribe is HMAC-signed, one-click, and flips both tables immediately.
- Shared secret `SPROUTSCORE_UNSUB_SECRET` must match the mailer's copy so its
  links verify here. Drip templates use `{{unsub_url}}` placeholders and
  `go.mehyar.us` links must be minted before any future send.
